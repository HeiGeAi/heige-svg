# 一篇 Markdown，直接排成公众号文章

没有动图的文章，直接写 Markdown 就行。

**加粗会标成强调色**，`行内代码`也支持。

## 提示词卡

代码块会排成提示词卡，读者长按就能复制。【方括号】里的字会标成黄底，提醒读者换成自己的。

```prompt 整理会议纪要
你是我的会议秘书。下面是一段会议录音的文字稿，请整理成纪要：

要写清楚：
1 这次会定了哪几件事；
2 每件事谁负责，什么时候交；
3 还没定下来的问题。

不要编没说过的内容，拿不准的标出来。会议主题是【填你的会议主题】。
```

## 话术卡

一句话的示范，用话术卡：

```say 交代完规矩，这样说
先别动手，用三句话复述一遍你要做什么，我确认了你再开始。
```

- 列表照常写
- 引用用大于号

> 编译后打开 console.html，顶栏可以一键复制标题、摘要、封面图和正文。
